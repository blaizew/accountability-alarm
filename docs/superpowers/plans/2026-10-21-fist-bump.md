# Fist Bump Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the "Doing It ↑" button with a tappable 👊 that grows in, gives a haptic hit, bursts confetti, leaves by a random animation, and resolves the alarm the same way the button did.

**Architecture:** Pure logic (enums, palettes, random picks, send-off selection) lives in Foundation-only files under `Bump/Logic/` and is tested by a `swiftc` script, because the Xcode project has no test target. SwiftUI views under `Views/Bump/` compose a `BumpStageView` that `ConversationView` shows in place of the chat once `actionAuthorized` is true. A `HapticService` wraps Core Haptics with UIKit fallbacks. Confetti is one `Canvas` inside a `TimelineView`.

**Tech Stack:** SwiftUI, SwiftData (unchanged), Core Haptics, UIKit feedback generators, `ImageRenderer`. No packages.

**Spec:** `docs/superpowers/specs/2026-10-21-fist-bump-design.md`

## Review Focus

1. Coach calls `authorize_action` with no text in the same response: the stage shows with an empty send-off slot and no crash. Test in Task 1 (`BumpSendOff.pick`).
2. User taps the fist while it is still growing, or taps twice after the bump: exactly one `resolveAction`. Test in Task 1 (`BumpPhase.canBump`) and the guard in Task 5.
3. Coach authorizes on the turn that hits the turn limit: outcome is compliance, not overridden. Test in Task 1 (`BumpRules.shouldOverrideForTurnLimit`).
4. Core Haptics unavailable (simulator, older device): fallback generators fire, no crash. Covered by the fallback branch in Task 2 and the simulator run in Task 7.
5. Reduce Motion on: no confetti, no breathing, removal is a fade, haptic still plays. Covered by the `reduceMotion` branch in Task 5; reviewer reads it.

### Task 3: ConfettiView

**Files:**
- Create: `Views/Bump/ConfettiView.swift`
- Create: `Views/Bump/ConfettiShapeDrawing.swift`

**Interfaces:**
- Consumes: `ConfettiPattern`, `ConfettiShapes`, `ConfettiPalette`, `ConfettiPalettes.usable` (Task 1).
- Produces: `struct ConfettiView: View { init(pattern: ConfettiPattern, shapes: ConfettiShapes, palette: ConfettiPalette, density: Double, size: Double, origin: CGPoint, countMultiplier: Double = 1.0) }`. Plays once from first appearance; total run 2.0 s; the view draws nothing after that. `origin` is in the view's own coordinate space. `static let duration: TimeInterval = 2.0`.

- [ ] **Step 1: Implement the particle system**

One `TimelineView(.animation)` wrapping a `Canvas`. Particles are a `[Particle]` struct array created on first draw from a `seed` state (so a redraw does not re-spawn), each with `birth`, `position`, `velocity`, `rotation`, `spin`, `shapeIndex`, `color`, `size`, `life`. Per frame integrate with gravity 900 pt/s², drag 0.98 per frame at 60 fps (use dt), and a horizontal wobble `sin(t * 6 + phase) * 30` pt/s. Alpha goes to zero over the last 20 percent of `life`.

Pattern spawns, counts before `density` and `countMultiplier`:
- `pop`: 120 at `origin`, direction uniform 0 to 360 degrees, speed 350 to 700 pt/s, life 1.4 to 2.0 s.
- `spray`: 100 over the first 0.4 s at `origin`, direction within 35 degrees of straight up, speed 700 to 1000 pt/s.
- `fireworks`: 60 at `origin` at 0 s, 60 at `origin.x - 0.25 * width` at 0.15 s, 60 at `origin.x + 0.25 * width` at 0.30 s. Same spread as `pop`.
- `rain`: 150 spawned over 1.2 s at random x across the width at y = -20, speed 150 to 300 pt/s downward, wobble doubled; plus 30 `pop` particles at `origin` at 0 s.

- [ ] **Step 2: Implement the shapes in `ConfettiShapeDrawing.swift`**

`enum ConfettiShapeDrawing { static func draw(_ shapes: ConfettiShapes, index: Int, in ctx: inout GraphicsContext, rect: CGRect, color: Color, symbols: [Image]) }` plus `static func symbolNames(for: ConfettiShapes) -> [String]`. Shape lists per the spec table: `clean` squares; `classic` circle, short strip, long strip, zig-zag, semicircle; `stars` circle + `star.fill`; `sparkles` circle, `sparkle`, 4-point path; `love` `heart.fill`, circle, `suit.heart.fill`; `cake` circle, `star.fill`, rounded sprinkle; `bubbles` two stroke widths of hollow circle; `garden` circle, 5-petal flower path, `leaf.fill`; `cards` the four `suit.*.fill`; `snow` circle, `snowflake`. Path shapes: `ctx.fill(path, with: .color(color))`. Symbol shapes: `var img = ctx.resolve(Image(systemName: name).renderingMode(.template)); img.shading = .color(color); ctx.draw(img, in: rect)`. Rotate per particle with `ctx.translateBy` + `ctx.rotate(by:)` inside a `ctx.drawLayer` so transforms do not leak between particles.
